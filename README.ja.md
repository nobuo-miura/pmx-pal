# PMX Pal

[English](README.md) | [日本語](README.ja.md)

PMXモデルをmacOSデスクトップ上に表示する、透過ウィンドウのマスコットアプリです。

## 現在できること

- PMXファイルと相対パスのテクスチャを読み込む
- 背景透過・常に手前のウィンドウにモデルを表示する
- 移動・回転・固定の3つのカメラ操作モードを切り替える
- カメラを移動・回転・拡大縮小してモデルの表示を調整する
- 複数のVMDモーションを読み込み、約12秒ごとに待機モーションを切り替える
- MMD向けBullet Physicsで髪・服・装飾などの物理演算を行う
- 目線なし・カメラ目線・マウスカーソル追従を切り替える
- マウスカーソル追従はウィンドウ外でも動作する
- ウィンドウ位置とサイズ、選択したPMX・VMD、操作モード、目線モードを保存する
- モデルごとにカメラの位置・回転・拡大率を保存する
- 日本語や空白を含むファイルパスを扱う

## 開発

必要な環境：

- macOS
- Node.js 26（安定版）
- npm 11

```sh
npm ci
npm run dev
```

テスト、型チェック、ビルド：

```sh
npm test
npm run check
npm run build
```

GitHub Actionsでも同じテスト、型チェック、ビルドを実行します。

macOS用のZIPファイルを作成：

```sh
npm run dist:mac
```

DMGを作成：

```sh
npm run dist:dmg
```

## 操作

- 上部バーのドラッグ：ウィンドウを移動
- 上部メニュー表示中の「✥」をドラッグ：ウィンドウを移動
- 上部バー：操作が止まると3秒後に隠れ、マウスを動かすと再表示
- 非表示時にウィンドウ上端へカーソルを合わせる：上部バーを再表示
- macOSメニューバーの「PMX Pal」：PMX・VMD選択、操作・目線モード、待機、最前面、終了
- 上部の「移動／回転／固定」：カメラ操作モードを選択
- 「移動」モード：ドラッグでカメラを上下左右に移動
- 「回転」モード：ドラッグでカメラを回転
- 「固定」モード：移動、回転、拡大・縮小を無効化
- 「移動」「回転」モード：トラックパッドのスクロールまたはピンチで拡大・縮小
- 「動作」：待機用VMDモーションを選択（複数選択可）
- 「待機」：登録したVMDモーションの再生を切り替え
- 「物理」：MMD物理演算のオン・オフを切り替え
- 上部の「目線なし／カメラ／カーソル」：目線モードを選択
- 「カメラ」：キャラクターの目・頭・首をカメラへ向ける
- 「カーソル」：ウィンドウ外を含むマウスカーソル位置を追う
- 右クリックまたは `M` キー：メニューを表示
- 右下の斜線ハンドルをドラッグ：ウィンドウサイズを変更
- 「前面」：常に手前に表示する設定を切り替え
